# 测试计划

> 对应 `mvp-plan.md` 全部已落地范围（一期闭环 + P2-A/B/C/D）。用例与 `../domain.md` 规则编号一一对应，手工验收步骤见 `acceptance.md`，本文不重复编号体系。
> 执行前提：测试账号 admin@chishafan.local / admin1234（ADMIN）、demo@chishafan.local / user1234（USER）已由 seed 写入。

## 1. 目标与范围

- **目标**：开放注册前确认核心链路（浏览 → 推荐/搜索 → 详情 → 收藏/就餐 → 偏好 → AI 对话）与账号安全（注册/登录/找回/换绑/注销/禁用）在全绿自动化之外，手工回归无阻塞缺陷。
- **范围内**：用户端 5 主 tab + 二级页、管理后台全部页面、`/api/**` 全部接口、CI 流水线。
- **范围外**（见 mvp-plan P2-E）：头像上传、对象存储/CDN、拼音搜索、评分评论、支付、PWA。本期不测。

## 4. 手工回归清单（发版前必跑）

> 每项标注对应规则；失败即阻塞发布。移动端页面用浏览器设备模拟（375px）+ 桌面各跑一遍主链路。

### 4.1 账号与认证（AUTH / DATA-03）

- [ ] 注册：邮箱唯一、手机号可空但填了必须唯一、密码 <8 位被拒；注册成功直接登录（AUTH-04）
- [ ] 登录失败 5 次后第 6 次返回 429 中文提示；成功登录后计数清零（AUTH-13）
- [ ] 找回密码：不存在的邮箱同样返回成功；`devResetUrl` 可完成重置；token 复用/过期返回 400；重置后旧会话 401、旧密码失效（AUTH-14）
- [ ] 邮箱换绑：确认前原邮箱可登录、新邮箱不可；点确认链接后新邮箱可登录；10 分钟第 6 次申请 429（AUTH-11/15）
- [ ] 手机号换绑：`devCode` 完成确认；输错 5 次作废；清空手机号不需要验证码（AUTH-16）
- [ ] 改密后其他设备下一次请求 401，本机不被踢下线（AUTH-09/12）
- [ ] 注销后：登录失败、资料 401、原邮箱/手机号不能再注册、收藏与历史保留（AUTH-12 / DATA-02/03）
- [ ] 后台禁用用户：该账号登录 403、旧会话立即失效；启用后恢复；管理员不能禁用/改角色/重置自己（AUTH-17 / ADMIN-03）

### 4.2 推荐与一餐（DISH / MEAL / PREF）

- [ ] 首页抽签只出两种形态：单品餐 或 主食+1~3 菜（组合餐恰好 1 主菜，素菜/汤可选）（MEAL-01~06）
- [ ] 主食来自全局池（米饭/馒头/面条/粥/饼），不是 Dish 记录、不可收藏（MEAL-05）
- [ ] 「换一个」连点至候选池耗尽后自动重抽，不出现「没有可推荐的菜」（DISH-04 / MEAL-08）
- [ ] 去重窗口三档（不限/3天/7天）切换后回首页自动重抽；0 天允许推荐今天吃过的（DISH-05 / N28）
- [ ] 设置忌口过敏原后，命中菜绝不出现，即使候选筛空也只返回空态（PREF-02 / MEAL-08 例外）
- [ ] 辣度上限硬过滤；喜欢菜系 ×3 / 不喜欢 ×0.2 是软降权（偶尔仍抽到属预期）（PREF-03/04）
- [ ] 「不感兴趣」后 7 天内随机与 AI 都不再推荐该菜；「我的 → 不感兴趣的菜」可撤销（PREF-11）
- [ ] 断网/关闭定位时首页照常出签，`ambient` 为空不报错（PREF-07 fail-open）

### 4.3 列表 / 搜索 / 详情 / 收藏 / 历史

- [ ] 菜品库：分类筛选 + 关键词搜索（300ms 防抖、大小写不敏感）可叠加；上拉加载、下拉刷新（DISH-03 / N15 / N26）
- [ ] 搜索历史本机最多 10 条、去重置顶、可清空、不上传；空词不记录（SEARCH-01/02）
- [ ] 搜索/筛选无结果时出现相近分类 + 热门菜兜底，可点击跳出（SEARCH-03）
- [ ] 详情页收藏/取消收藏幂等；刷新后状态正确；`(userId,dishId)` 无重复收藏（FAV-01~03）
- [ ] 「今天就吃它」同日同菜只记一条；浏览/刷新不写历史（HIST-02/03）
- [ ] 历史页左滑撤销有二次确认；仅 7 天内可撤；撤销后推荐池恢复该菜（HIST-04）
- [ ] 收藏/历史/偏好页要求登录，未登录跳转带 redirect，登录后回原页（N13）

### 4.4 AI 推荐（REC / TRACK）

- [ ] 未配置 `NUXT_LLM_API_KEY` 时返回友好 SSE error，前端不崩（REC-03）
- [ ] 流式打字机正常；多轮对话最多 6 轮；错误气泡不进下一轮历史（REC-05 / N24）
- [ ] 用户点名的菜不在候选池时，明确告知「菜品库里暂时没有」再推替代，不编造食材（REC-06）
- [ ] 登录用户第 31 次/游客第 6 次当日调用返回配额提示，且不产生上游请求（REC-07）
- [ ] 曝光/点击/就餐三类事件批量上报；断网时静默吞掉不影响主流程（TRACK-01~04）

### 4.5 管理后台（ADMIN）

- [ ] 非 ADMIN 访问 `/admin` 与 `/api/admin/*` 返回 403；未登录跳登录（AUTH-02/03）
- [ ] 菜品/分类 CRUD 全部软删除；列表「资料完整度」筛选（缺图/缺过敏原/缺食材）数量与库一致（ADMIN-06 / DATA-01）
- [ ] 批量上下架/改分类 ≤200 条、CSV 导入 ≤500 行；`dryRun` 预校验失败行给 Excel 行号；非法行不落库（ADMIN-07）
- [ ] 禁用用户/重置密码/菜品分类写操作均可在 `/admin/audit-logs` 查到，含操作人邮箱；审计无删除入口（ADMIN-02/04）
- [ ] 看板 7/30 天切换：趋势补零、热门菜与 DiningHistory 一致、零结果搜索与 AI 失败率有数据；空数据有空态（ADMIN-05）

### 4.6 工程与体验（SEO / 可靠性）

- [ ] `GET /api/health` 正常 200；停数据库后 503（3s 超时）（P2-19）
- [ ] 不存在路由显示品牌 404；图片加载失败有占位；暗夜模式三档切换全局生效（P2-21 / N31）
- [ ] 分享详情页有正确标题/封面；`robots.txt` 含 `/admin` `/api` 等 Disallow；`sitemap.xml` 只收公开页与在架菜（SEO-01/02）
- [ ] 请求日志带 `x-request-id`；5xx 可在结构化日志按 requestId 追溯（P2-19）

## 6. 通过标准（出口准则）

1. CI 全绿：lint / format:check / typecheck / test / e2e / build 全部通过。
2. §4 手工回归 100% 执行，无 P0/P1 缺陷遗留；P2 缺陷有 issue 记录且不阻塞主链路。
3. §3 自动化缺口中 1~4 项（账号安全 + 硬过滤）已补自动化或在 CI 中有等价覆盖。

## 7. 已知限制（测试时不报缺陷）

- 限流与 AI 配额为单机内存实现，多实例部署下不按预期（AUTH-13 / REC-07 注释已声明）。
- `RANDOM()` 全表扫描在千级数据量下无感知（DISH-08）；`ILIKE` 搜索在 5000 行或 P95>300ms 前不启用 `pg_trgm`（DATA-06）。
- 已注销账号的邮箱/手机号永久占用，不可复用（DATA-03 的 MVP 取舍）。
- 游客「不感兴趣」不落库，刷新即失效（PREF-11 预期行为）。
