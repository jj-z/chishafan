# 验收标准 (Acceptance Criteria)

对应 `mvp-plan.md` 中的步骤，必须满足以下标准才能进入下一步。

- 编号规则：`阶段-序号`，同一阶段内连续编号，新增项追加在所属阶段末尾，**不再复用旧版计划里的裸数字编号**。
- 「计划步骤」列指向 `mvp-plan.md` 的阶段条目或新增需求编号（N*/P2-*）；两者必须一一对应。
- 每条验收标准都要能在本机复现，涉及数据库的以库内查询结果为准，不以接口自述为准。
